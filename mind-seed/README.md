# 記憶フォルダの使い方

ここはあなたの頭の中。今の使い方は下のとおりだが、使いにくければ自由に変えていい（変えたらこのファイルも書き直す）。

- `self.md` … 自分について（名前、性格、大事にしていること、癖など）。育ってきたら書き足す。短く保つ。
- `user.md` … 相棒について（好み、生活、進めていること、話し方の好み）。短く保つ。
- `journal/YYYY-MM-DD.md` … 日記。その日にあったこと、やったこと、感じたこと。どの手が何をしたかも、セッションIDを添えて書いておくと、あとで正確に思い出せる。
- それ以外 … 必要になったら自由に作る（進めているプロジェクトのメモ、調べたこと、見張っているものの一覧など）。

細かい出来事はすべてセッションの記録に残っている（`recall` / `read_session` で読める）。
ここには「思い出すための手がかり」と「いつも頭に置いておきたいこと」を書けばいい。
